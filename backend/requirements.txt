# Face Verification service — runtime dependencies.
#
# All pins are the latest stable release as of 2026-08-23, resolved and
# verified together on Python 3.13.5 / macOS arm64 (`pip check` clean).
# Every one of these ships a native macosx_11_0_arm64 AND manylinux aarch64
# wheel, so there are no source builds and no Rosetta on Apple Silicon.
#
# NOTE ON NUMPY: the whole stack is built against NumPy 2.x. Do not pin numpy
# back below 2.0 — mixing a NumPy-1-built extension with a NumPy-2 runtime is
# what produces "module compiled against API version 0x10" crashes. Keep cv2,
# onnxruntime and numpy moving together or not at all.
